# 可观测性

## 是什么

**可观测性**是「发生了什么」的记录:每一次模型调用、每一次变更、每一个连接的
客户端。它回答「这东西跑得多频繁、效果如何、谁在用」。

下面所有内容都在 UI 的 **观测** 页面里。

## 运行日志

每一次模型调用 —— 来自 [Playground](./playground)、[Agent](./agents) 或
[Workflow](./workflows) —— 都会被记录:

- 时间戳与来源
- 提供方与模型
- Token 数(输入 / 输出,估算值)
- 延迟(毫秒)
- 状态(`ok` / `error`)

这是 AI 实际做了什么的记录。

## 统计指标

运行日志被聚合成几张概览卡片:

- **总运行次数**
- **成功 / 失败** 次数
- **估算 Token 总量**
- **平均延迟**
- 以及**按提供方**的拆分

## 审计日志

每一次*变更*单独记录:谁、在何时、改了什么。Prompt 的创建、更新、删除、
发布、回滚都会留下一条审计记录,包含操作、资源、key 和简短说明。

运行日志告诉你 AI 做了什么;审计日志告诉你人做了什么。

## 在线客户端

**在线客户端** 标签页列出每一条活跃的热更新连接 —— 当前正在监听变更的 SDK
实例和浏览器会话。每一条包含:

| 列 | 说明 |
|---|---|
| 类型 | `node-sdk`、`python-sdk`、`java-sdk` 或 `browser` |
| 应用 | 创建 SDK 时传入的 `appName` |
| 命名空间 | 它正在监听的环境 |
| IP 地址 | 它从哪里连接 |
| 连接时间 | 连接建立的时刻 |

这样你能一眼看到当前有哪些应用绑定到了 PromptOps。客户端如何连接见
[热更新](./hot-reload)。

## 对应的 API

| 数据 | 接口 |
|---|---|
| 运行日志 | `GET /api/runs` |
| 运行统计 | `GET /api/runs/stats` |
| 审计日志 | `GET /api/audit` |
| 在线客户端 | `GET /api/clients` |
